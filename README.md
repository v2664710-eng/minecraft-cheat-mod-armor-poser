# Cheat Mod - Armor Poser Exploit

Minecraft 1.21 Fabric мод с использованием Armor Poser бага для отправки команд на Command Block без проверки

## Возможности

✅ Меню с полем ввода команд (нажми `INSERT`)  
✅ Отправка команд через Armor Poser баг  
✅ Выдача Command Block'ов  
✅ Никаких проверок на сервере  
✅ Поддержка команд длиной до 512 символов  

## Установка

1. **Установи Fabric Loader** для версии 1.21
2. **Распакуй мод** в папку `mods/`
3. **Запусти игру** через Fabric профиль
4. Мод готов к использованию!

## Использование

### Открытие меню
- Нажми клавишу **`INSERT`**

### Отправка команды
1. Введи команду в поле (например: `give @s diamond_block 64`)
2. Нажми **"Отправить команду"** или **`ENTER`**
3. Команда отправится на стойку через Armor Poser

### Выдача предметов
- Нажми **"Выдать Command Block"** для получения блока

## Примеры команд

```
give @s diamond_block 64
setblock ~ ~1 ~ command_block
effect give @s speed 1000 255
tp @s 0 100 0
time set day
weather clear
```

## Как это работает?

Armor Poser - модель персонажа которая позволяет позировать. **Баг:** модуль не проверяет данные которые отправляет клиент, поэтому можно отправить любые данные вместо позы.

Этот мод использует эту уязвимость для отправки команд напрямую на сервер.

## ⚠️ Внимание

- Мод может быть использован только на серверах которые НЕ обновили Armor Poser
- На защищённых серверах мод может быть обнаружен
- Используй на свой риск!
